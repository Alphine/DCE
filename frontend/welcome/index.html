Product

What it does

One command view for the whole response cycle: what is happening, what it may lead to, what can be done, and who has agreed to do it.

  • Situation map

    A Leaflet map with country outlines and switchable layers, so hazards, shelters, stock and teams sit on one picture.

  • Hazard intelligence

    Rule packs for flood, tsunami, earthquake and wildfire. They are illustrative and hash-verified before use.

  • Simulation and planning

    Reproducible what-if runs and per-district allocation. The same inputs always give the same outputs.

  • Logistics

    Shelters, stock, teams and vehicles, with coverage gaps made visible so they can be closed.

  • Alerts and time series

    Alerts and observed series over time, so trends show up before they become emergencies.

  • Reports with verification

    Situation reports that carry their verification state, so readers can see what has been checked.

  • Missions with approval gate

    A mission does not run until a person has approved it. The agent cannot start one on its own.

  • Public warnings

    Warnings for the public in several languages, kept separate from the internal command view.

Trust

How trust is built

Four rules keep the system honest about what it knows, what it guessed, and who decided.

  1. Data is classed

    Every value is an observation, verified, simulated or a decision. Simulated values are never shown as observations.

  2. Two human gates

    A plan and a mission each need an explicit human approval before they take effect.

  3. Hash-chained audit log

    Each action is written to an append-only log where every entry hashes the one before it. Altering history breaks the chain.

  4. Sandboxed AI agent

    The AI agent only plans. Deterministic engines do the computation, so results can be reproduced and checked.

Offline-first

Keeps working when the network does not

Install it as an app (PWA) on a phone or laptop. With the network off, it still works with data you have already seen.

Actions you take wait in an outbox and are sent when the connection returns. A desktop build for Windows is published with the project releases.

  • Installable as an app (PWA)
  • Previously seen data is available with no network
  • Actions go to an outbox and sync when online
  • Windows desktop build from the project releases

Global scope

Usable across countries

Hazards and response do not stop at borders. Every record carries its country, and every view can be filtered by country.

  • Country codes on every record
  • Country filter on the map and on lists
  • Rule packs declare the countries they cover

Read before use

Honest limits

  • Thresholds are illustrative. Rule thresholds have not been validated against an authoritative standard.
  • Simulation is not observation. Simulation outputs show what a model predicts. They are not records of what happened.
  • Not for operational use yet. Do not use this product for real emergency decisions without validation for your own context.
