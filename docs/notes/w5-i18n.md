## Backend endpoints

| Method and path | Role | Notes |
| --- | --- | --- |
| `POST /api/warnings` | Analyst+ | Creates a DRAFT. Extra fields refused. `<` and `>` refused with 422. |
| `GET /api/warnings` | Viewer+ | All statuses, newest first, max 200. `?status=`, `?country=`. IDs only, no usernames. |
| `POST /api/warnings/{id}/publish` | Approver+ | Body `{content_sha256}`. Creator gets 403 `SELF_APPROVAL_NOT_ALLOWED`. Hash mismatch 409 `CONTENT_CHANGED`. Re-publish 409 `INVALID_STATE`. Audited. |
| `POST /api/warnings/{id}/withdraw` | Approver+ | PUBLISHED only, else 409. Audited. |
| `GET /api/public/warnings` | none | PUBLISHED only. Fields: id, title, body, lang, country_code, hazard_type, published_at. Max 100, newest first. `?lang=en|id`, `?country=`. Header `Cache-Control: public, max-age=60`. Rate limit 120 per IP per minute (reuses `app/ratelimit.py`). |

Content hash: SHA-256 of the canonical JSON of title, body, lang, country_code, hazard_type (country NULL when not given).
